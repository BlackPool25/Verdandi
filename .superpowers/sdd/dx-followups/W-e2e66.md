## Method (read before quoting)
- Sample: < N > fault episodes, deterministic seed < S >, from
  `artifacts/m0b_mass_*.parquet` (column-projection scan on
  episode_id+root_id; full frames read only for sampled shards).
- Trigger per episode: ORACLE first `fault_mask == 1` tick (the frozen
  detector model file is absent from this tree, so detector triggers cannot
  be replayed). This is a **perfect-retrieval assumption**: what is MEASURED
  is gate coverage + selective accuracy CONDITIONAL on detection.
- Scores per episode: MEASURED max |prefix-z| over the post-trigger window
  (same math as `scripts/report_incident.measure_scores`), never invented.
- Gate: live `diagnose_incident(..., calibrator=load_calibrator())` with
  served tau=0.739 (T=2.58, a=6.4202, b=-2.7236). Single-node reports
  (`abstain='single-node'` from `src/report.py`) count as abstain, matching
  the `abstain_paths` scope mapping in `scripts/report_incident.py`.
- GT (`root_id`/`fault_mask`/`family`) used for trigger + scoring only
  (evaluation-only, per `src/diagnose.py` docstring).
